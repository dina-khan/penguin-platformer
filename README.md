# Penguin Platformer

A 2D side-scrolling penguin platformer built with p5.js for the 
University of London CM1005 Introduction to Programming module.

🎬 **[Video Demo](https://drive.google.com/file/d/1dV88suW3kBHULqN338zCgJCNyPDLfTf4/view?usp=sharing)** 

🎮 **[Play in Browser](https://dina-khan.github.io/penguin-platformer/)**

## How to Play
- **A / D** - move left / right
- **W** - jump
- Collect snowflakes to score points
- Avoid enemy fireballs
- Avoid drowning in canyons
- Reach the flagpole to complete the level

## Features
- Procedurally drawn character with 5 animation states (idle, left, right, jumping, falling)
- Parallax scrolling background with mountains, clouds and trees
- Snowfall particle animation
- Enemy fireballs
- Icy platform and canyon collision detection
- Score counter, lives system and sound effects
